# Flight Price Prediction System

A full-stack web application that estimates the price of a flight from its airline, route, schedule, number of stops, travel class, and departure date. The React interface sends the selected flight details to a Flask API, which returns a prediction from the bundled machine-learning model.

> **Note:** Predictions are estimates generated by a model and are not live fares or booking quotes.

## Features

- Predict a flight price in Indian rupees (₹).
- Select from supported airlines, Indian cities, departure and arrival time bands, stop counts, and Economy or Business class.
- Specify a departure date; the API derives the number of days until departure.
- Use the included pre-trained model without training it again.

## Tech stack

- **Frontend:** React, Vite, Tailwind CSS, Axios
- **Backend:** Python, Flask, Flask-CORS
- **Machine learning:** scikit-learn Linear Regression

## Getting started

### Prerequisites

- Python and pip
- Node.js and npm

### 1. Install backend dependencies

From the repository root, create and activate a virtual environment, then install the API and model dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install Flask flask-cors scikit-learn
```

If PowerShell blocks environment activation, use the virtual environment's Python directly:

```powershell
.\.venv\Scripts\python.exe -m pip install Flask flask-cors scikit-learn
```

The model is loaded from `backend\model.pkl` when the API starts. Pickled scikit-learn models can depend on the scikit-learn version used to create them; use a compatible version if loading the bundled model fails.

### 2. Start the Flask API

From the repository root:

```powershell
python backend\app.py
```

The API runs at `http://127.0.0.1:5000`.

### 3. Install and start the frontend

In a second terminal:

```powershell
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite (typically `http://localhost:5173`). During development, Vite forwards requests from `/api` to the Flask server at `http://127.0.0.1:5000`. To use a different backend address, set `VITE_BACKEND_URL` before starting Vite.

## Prediction API

### `POST /predict`

The request body must be JSON. The field values are case-sensitive:

```json
{
  "airline": "Vistara",
  "source_city": "Delhi",
  "departure_time": "Morning",
  "stops": "one",
  "arrival_time": "Afternoon",
  "destination_city": "Mumbai",
  "class": "Economy",
  "departure_date": "2027-01-15"
}
```

Supported values:

| Field | Values |
|---|---|
| `airline` | `AirAsia`, `Indigo`, `GO_FIRST`, `SpiceJet`, `Air_India`, `Vistara` |
| `source_city`, `destination_city` | `Delhi`, `Hyderabad`, `Bangalore`, `Mumbai`, `Kolkata`, `Chennai` |
| `departure_time`, `arrival_time` | `Early_Morning`, `Morning`, `Afternoon`, `Evening`, `Night`, `Late_Night` |
| `stops` | `zero`, `one`, `two_or_more` |
| `class` | `Economy`, `Business` |
| `departure_date` | Date in `YYYY-MM-DD` format |

Successful response:

```json
{
  "prediction": 5432.1
}
```

The response contains the estimated price rounded to two decimal places. Invalid or missing field values return an error response.

## Model and data

The included notebook documents data exploration and training of a scikit-learn Linear Regression model. The API uses the pre-trained artifact in `backend/model.pkl`; retraining is not required to run the application. The dataset is included in `backend/flight.csv`.
